Music software

  • Aug 2026 Pink Trombone plugin A synth that imitates the human voice by simulating air moving through a vocal tract. An unofficial plugin based on Neil Thapen's Pink Trombone. code
  • Aug 2026 Violin synth A violin built from the physics of bowing rather than from samples. The string model is fitted to 91 notes measured from a solo violin recording, and adds a shared violin body, sympathetic open strings and expressive vibrato. VST3/AU plugin.
  • Oct 2026 transcribe-midi Turns a link or audio file into MIDI. It separates the instruments first, then transcribes each one with the model that suits it. code
  • Oct 2026 Sample organizer Classifies a sample library by sound (kick, snare, loop…), measures BPM and key, and finds similar sounds with CLAP audio embeddings. Tested on about 27,500 files. in development
  • Oct 2026 multitrack-stems Splits a finished song into 13 stems that sum back to the original mix, by chaining five source-separation models. code
  • Sep 2026 HandCC Webcam hand tracking as a MIDI controller for Ableton Live. code
  • Aug 2026 Voice Splitter An Ableton device that splits a MIDI clip into one track per voice. code
